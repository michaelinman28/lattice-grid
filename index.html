Lattice Grid

A dependency-free JavaScript data grid built from scratch, with grouping, pivoting, tree data, master/detail, range selection, charts, Excel export and more.

What this example turns on

  • Move columns: drag a column header left or right
  • Sort: click a header. Shift+click to sort by more than one column
  • Filter: type in the boxes under the headers. Number columns accept >90000 or 2..4. "All" opens a checkbox list
  • Reorder rows: drag the ⠿ handle, or press Alt+↑/Alt+↓. This pauses while a sort or filter is active
  • Choose columns: use the Columns button to show or hide columns
  • Paging: the Paging button switches between one scrolling list and pages, without reloading the grid

The configuration

new LatticeGrid('#simpleGrid', {
  columns, rows, rowId: (r) => r.id,
  rowReorder: true,          // drag-and-drop rows
  columnMove: true,          // drag headers to reorder columns (default)
  floatingFilters: true,     // filter boxes under each header (default)
  // everything else switched off:
  toolbar: false, groupPanel: false, sideBar: false, statusBar: true,
  columnMenu: false, contextMenu: false, rangeSelection: false,
  fillHandle: false, readOnly: true,
});
// column picker: grid.setColumnVisible(id, true | false)
// paging on/off: grid.setPagination(true, 25) / grid.setPagination(false)

Try this

  • Drag the ⠿ handle to reorder rows. Select several rows first to move them together. Reordering pauses while a sort, filter, grouping or pivot is active
  • Drag a column header into the group bar, or into the side panel's zones
  • Drag across cells to select a range. The status bar shows its sum, avg, min and max
  • Right-click a range and choose Chart range
  • Drag the small blue square (the fill handle) down to extend a series
  • Double-click Qty, Price, Status, Rating or Notes to edit
  • Number floating filters accept >100, <=5, 10..20

Keyboard

  • ↑↓←→ move · Shift+arrows extend range
  • Enter/F2 edit · Esc cancel · Tab next cell
  • Ctrl+C / Ctrl+V copy / paste (works with Excel)
  • Ctrl+Z / Ctrl+Y undo / redo · Delete clear
  • Space select row · Ctrl+A select all cells · Ctrl+F find
  • Alt+↑ / Alt+↓ move the focused (or selected) rows
  • Shift+click a header for multi-column sort
